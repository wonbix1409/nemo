# Немо 0.1 — подробная инструкция

Прячет ФИО, организации, адреса, ИНН, СНИЛС, ОГРН, КПП, БИК, счета, карты, телефоны,
почту и паспорта перед отправкой текста в нейросеть, а потом возвращает настоящие данные в ответ.
Всё работает на компьютере пользователя, без интернета.

## Быстрый старт (Windows)

1. Установите **Python 3.12** с python.org и при установке отметьте **Add python.exe to PATH**.
2. Распакуйте архив, например в `C:\Nemo`.
3. Запустите **`run.bat`**. В первый раз он создаст окружение и скачает зависимости (~100 МБ, пара минут).
4. Пока внизу написано «Загружаю модель распознавания имён…», скрываются только шаблоны. Через несколько секунд включатся имена, организации и адреса.

## Как пользоваться

1. **① Скрыть**: вставьте текст или откройте файл (.docx, .txt) → «Скрыть данные» (Ctrl+Enter).
   Проверьте правую панель: всё ли скрыто. Что-то пропущено — выделите это слева и нажмите «Скрыть выделенное».
2. «Скопировать для нейросети» → вставьте в GigaChat / Алису / ChatGPT.
   С галочкой «Добавлять подсказку» в начало добавляется просьба не менять метки.
3. **② Вернуть**: вставьте ответ нейросети → «Вернуть данные» → «Скопировать результат».
4. **Метки сеанса**: таблица «метка → значение». Сеанс сохраняется, поэтому ответ можно вернуть и после перезапуска.
   «Новый сеанс» очищает таблицу.
5. **Словарь…**: фразы, которые скрываются всегда (клиенты, проекты, внутренние коды).

Данные лежат в `%APPDATA%\Nemo\`: `session.json` (таблица меток), `dictionary.txt` (словарь).

## Сборка в .exe

Запустите **`build.bat`**. Он ставит PyInstaller, делает самопроверку и собирает `dist\Nemo\Nemo.exe`.
Переносить нужно всю папку `dist\Nemo` (~140 МБ, в основном модель имён).
Проверка без окна: `python app.py --selftest` (лог пишется в `%APPDATA%\Nemo\selftest.log`).

## Сборка .exe на GitHub (без Python на компьютере)

В проекте есть `.github/workflows/build-windows.yml`. Загрузите проект в репозиторий на GitHub:
при каждом push в `main` GitHub на Windows-машине прогонит тесты, соберёт `Nemo.exe`, проверит его
и выложит `Nemo-windows.zip` во вкладку **Actions → последний запуск → Artifacts**.
Тег `v0.1.0` дополнительно создаёт релиз с этим zip.

## Как Немо связывает упоминания одного человека

Один человек получает один номер, а форма упоминания — суффикс:

| В документе | Метка | Вернётся как |
|---|---|---|
| Белоусова Аркадия Геннадьевича / Белоусов Аркадий Геннадьевич | `[ЧЕЛОВЕК_1]` | Белоусов Аркадий Геннадьевич |
| Аркадию Геннадьевичу | `[ЧЕЛОВЕК_1.ИО]` | Аркадий Геннадьевич |
| Белоусов А.Г. / А.Г. Белоусов | `[ЧЕЛОВЕК_1.ИНИЦ]` | Белоусов А.Г. |
| ИП Гусейнова Лейла Рашидовна | `ИП [ЧЕЛОВЕК_2]` | ИП Гусейнова Лейла Рашидовна |

Если нейросеть сама напишет `[ЧЕЛОВЕК_3.ИО]` («Уважаемый [ЧЕЛОВЕК_3.ИО]!»), Немо построит имя-отчество из полного ФИО.
Не скрываются: страны (Россия, РФ), госорганы (МВД, ФНС, ГУ МВД), суды — это не персональные данные, а метки сбивали нейросеть.

## Известные ограничения прототипа

- **Падежи при возврате.** ФИО и места возвращаются в той форме, что записана в таблице:
  «полномочия Шпаков Дмитрий Олегович» вместо «Шпакова Дмитрия Олеговича». Следующая задача — склонение при возврате.
- **«Ольга Владимировна» и «Ткаченко О.В.»** без полного ФИО в тексте остаются разными людьми: связать их без фамилии надёжно нельзя.
- **Суммы и даты не скрываются** (специально: они обычно нужны для анализа). Добавим как опцию.
- **Модель имён ошибается.** Перед отправкой нужно глазами проверить правую панель.
- `session.json` хранится открытым текстом. Шифрование через Windows DPAPI — в планах.
- Нейросеть может восстановить контекст и без имён. Немо снижает риск, но не делает текст полностью анонимным.
