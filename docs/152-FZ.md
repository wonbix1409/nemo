# Немо и 152-ФЗ

Это не юридическая консультация. Здесь — что Немо делает технически и что из этого следует
для компании. Решение о порядке работы с нейросетями принимает оператор персональных данных.

## Какой это метод обезличивания

Немо заменяет ФИО, реквизиты и контакты метками (`[ЧЕЛОВЕК_1]`, `[ИНН_1]`) и хранит таблицу
соответствия отдельно. В терминах Приказа Роскомнадзора от 19.06.2025 № 140 (действует с 01.09.2025)
это **метод введения идентификаторов**.

## Чего Немо не делает

- **Не превращает текст в «не персональные данные».** Обезличивание по Приказу № 140 обратимо:
  по таблице соответствия данные восстанавливаются. Текст с метками нужно считать персональными
  данными с пониженным риском, а не данными вне закона. Использование нейросети — тоже обработка.
- **Не гарантирует, что человека нельзя узнать.** Суммы, даты, должности, город и детали сделки
  остаются в тексте, если их не скрыть. Даты и суммы можно скрывать автоматически («Настройки»),
  остальное — словарём или кнопкой «Скрыть выделенное».
- **Не решает вопрос передачи.** Считать ли отправку обезличенного текста провайдеру нейросети
  передачей персональных данных, прямо не урегулировано.

## Что сделано в программе под требования

| Требование | Как в Немо |
|---|---|
| Ключ (таблица соответствия) хранится отдельно от обезличенных данных | Таблица остаётся на компьютере сотрудника, в нейросеть уходит только текст с метками. На диске таблица зашифрована ключом учётной записи Windows (DPAPI). Папку можно вынести на отдельный диск; можно не сохранять таблицу вовсе |
| Хранить ключ не дольше нужного | Автоочистка сеанса через N дней (по умолчанию 7), кнопка «Новый сеанс» затирает файл |
| Учёт операций | Журнал `journal.csv`: время, пользователь, действие, количество по типам — без самих данных |
| Снижение риска узнать человека по косвенным данным | Скрытие дат и сумм по выбору, словарь компании |

## Что нужно компании помимо программы

По Приказу № 140 оператор до обезличивания определяет состав данных и субъектов и оценивает
достаточность метода для своей цели. На практике это:

1. **Оценка достаточности метода** для ваших документов и задач: какие типы документов можно
   отправлять в нейросеть, какие косвенные данные скрывать обязательно.
2. **Локальный акт**: кто и для чего может пользоваться нейросетями, какие сервисы разрешены,
   что запрещено отправлять даже с метками.
3. **Учёт**: журнал операций (в Немо есть) и порядок хранения и уничтожения таблиц соответствия.
