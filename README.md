# Немо

**Обезличивание документов перед отправкой в нейросеть — локально, без интернета.**

Немо заменяет ФИО, организации, адреса, реквизиты и контакты метками вида `[ЧЕЛОВЕК_1]`, `[ИНН_1]`.
Текст с метками можно спокойно отправить в GigaChat, Алису, ChatGPT или любую другую нейросеть,
а ответ вставить обратно: Немо вернёт на место настоящие данные.

```
Иванов Иван Петрович, ИНН 7707083893   →   [ЧЕЛОВЕК_1], ИНН [ИНН_1]   →   нейросеть   →   ответ с настоящими данными
```

## Что скрывает

| Шаблоны (с проверкой контрольных сумм) | Модель распознавания (Natasha) |
|---|---|
| ИНН, СНИЛС, ОГРН / ОГРНИП, номера карт (Луна) | ФИО — с учётом падежей |
| КПП, БИК, расчётные и корр. счета | Организации |
| Телефоны, e-mail, паспорт, адреса (улица, дом) | Города и регионы |

Плюс словарь пользователя (всегда скрываемые фразы) и ручное скрытие выделенного.

## Инструменты

- **Python 3.12** — язык приложения
- **tkinter / ttk** — интерфейс (встроен в Python, без лишних зависимостей)
- **[Natasha](https://github.com/natasha/natasha)** (Slovnet, Navec, pymorphy2) — локальное распознавание имён, организаций и мест в русском тексте, приведение к начальной форме
- **Регулярные выражения + контрольные суммы** — ИНН, СНИЛС, ОГРН, карты (алгоритм Луна)
- **python-docx** — чтение .docx
- **PyInstaller** — сборка в `Nemo.exe`
- **pytest** — тесты ядра
- **GitHub Actions** (`windows-latest`) — автосборка и проверка `.exe` при каждом push

## Быстрый старт

**Готовая сборка:** вкладка **Actions** → последний успешный запуск → артефакт `Nemo-windows` → распаковать → `Nemo.exe`.

**Из исходников (Windows):** установить Python 3.12 (галочка *Add to PATH*) → `run.bat`.
Собрать exe локально → `build.bat`.

Подробная инструкция и известные ограничения — [docs/USAGE.md](docs/USAGE.md).

## Структура

```
app.py                   интерфейс, запуск, --selftest
nemo_core/detectors.py   шаблоны и Natasha
nemo_core/anonymizer.py  метки, обратная подстановка, сеанс
nemo_core/files.py       чтение .docx / .txt
tests/                   тесты ядра
samples/                 тестовый договор с выдуманными данными
.github/workflows/       сборка Nemo.exe
```

## Приватность

Всё работает на компьютере пользователя. Таблица соответствий «метка → значение» хранится
в `%APPDATA%\Nemo\` и никуда не отправляется. Немо снижает риск утечки, но не делает текст
полностью анонимным: по контексту нейросеть иногда может догадаться, о ком речь.
